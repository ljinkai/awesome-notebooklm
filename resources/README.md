## Related AI Research Tools

These tools are not NotebookLM but solve related problems:

- **[Elicit](https://elicit.com)** — AI literature search for academic papers
- **[Consensus](https://consensus.app)** — Evidence-based AI search
- **[Perplexity](https://perplexity.ai)** — AI-powered web search with citations
- **[Claude](https://claude.ai)** — Anthropic's assistant; handles very long documents well, good for single-source deep reading
- **[ChatGPT](https://chatgpt.com)** — OpenAI's assistant; can analyze uploaded documents

## Prompt Engineering Foundations

NotebookLM uses a customized Gemini model. General prompting principles apply:

- **[Prompting Guide (promptingguide.ai)](https://www.promptingguide.ai)** — Comprehensive reference for prompting techniques.
- **[Learn Prompting](https://learnprompting.org)** — Free, open-source prompting course.
- **[Google's Prompting Essentials](https://grow.google/certificates/prompting-essentials/)** — Google's own course on prompting, relevant since NotebookLM uses Gemini.
