# Workflows

Step-by-step guides for common NotebookLM use cases. Each workflow is designed to be repeatable and produce consistent results.

## Available Workflows

- [Research Workflow](research-workflow.md) — Systematic literature review and research synthesis
- [Writing Workflow](writing-workflow.md) — From raw sources to polished draft
- [PKM Workflow](pkm-workflow.md) — Personal knowledge management with NotebookLM + Obsidian/Notion

## Choosing the Right Workflow

| Goal | Workflow |
|------|----------|
| Reviewing academic literature | Research |
| Writing an article, report, or essay | Writing |
| Building a long-term knowledge base | PKM |
| Understanding a book deeply | Reading prompts + PKM |
| Processing meeting notes | Meeting prompts |

## Workflow Principles

These workflows share a common structure:

1. **Source curation first.** The quality of NotebookLM output is bounded by the quality of your sources. Spend time selecting and organizing sources before prompting.

2. **Separate exploration from synthesis.** Use early prompts to understand what is in your sources (exploration). Use later prompts to combine and apply that understanding (synthesis).

3. **Save good outputs as Notes.** When NotebookLM produces a useful response, save it as a Note in the notebook. Notes persist across sessions and become part of the context the model draws from.

4. **Iterate in sessions.** Each chat session builds context. Start a session with orientation ("I'm working on X and have reached step Y") so the model can build on prior work.
