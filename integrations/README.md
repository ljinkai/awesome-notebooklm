# Integrations

Guides for connecting NotebookLM with other tools in your workflow.

## Available Guides

- [Obsidian](obsidian.md) — Bidirectional workflow between NotebookLM and your Obsidian vault
- [Notion](notion.md) — Routing NotebookLM outputs into Notion databases
- [Readwise](readwise.md) — Feeding Readwise highlights into NotebookLM as sources

## Integration Philosophy

NotebookLM does not currently offer a native API or direct integrations with third-party tools. All integrations in this section are **manual workflows** — deliberate copy-paste processes with clear steps.

This is not a limitation to work around; it is a feature to embrace. Manual workflows force you to make active decisions about what is worth keeping. The friction of copy-paste is a filter.

Future integrations may become possible via Zapier, Make, or Google's own automation tools as NotebookLM evolves. Check this list for updates.

## What NotebookLM Outputs Can Be Integrated

| Output Type | Export Method | Best Destination |
|-------------|--------------|-----------------|
| Chat responses | Copy text | Obsidian / Notion note |
| Notebook Notes | Copy from Note panel | Obsidian permanent note |
| Audio Overview scripts | Not directly accessible | — |
| Source summaries | Copy from source panel | Notion database |
| Study guides | Copy from Studio panel | Obsidian / Notion |
| Briefing documents | Copy from Studio panel | Email / Docs |
